# MoneyCoach Jr. 💰

A fun and educational money management app designed specifically for children to learn about finances, track expenses, and achieve savings goals.

## 🌟 Features

### For Kids
- **💰 Money Management**: Track allowance and spending money
- **📊 Expense Tracking**: Log purchases with fun categories and emojis
- **🎯 Savings Goals**: Set and work towards financial goals
- **🏆 Achievement System**: Celebrate completed savings milestones
- **📱 Kid-Friendly Interface**: Colorful, intuitive design with emojis and animations

### For Parents
- **🔒 Secure Parent Dashboard**: PIN-protected access to management features
- **💵 Add Money**: Easily add allowance or bonus money to child's account
- **📈 Analytics & Reports**: View spending patterns and generate reports
- **⚙️ Settings**: Manage currency, PIN, and app preferences
- **📧 Export Reports**: Generate financial summaries for record keeping

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/moneycoach-jr.git
cd moneycoach-jr
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

### Building for Production

```bash
npm run build
```

The built files will be in the `dist/` directory.

## 🎮 How to Use

### First Time Setup
1. Open the app and click "Start App" on the landing page
2. Begin by adding money to your balance
3. Start tracking expenses or create your first savings goal

### For Parents
1. Click the "Parents" button in the top-right corner
2. Enter the PIN (default: 1234)
3. Access parent dashboard to:
   - Add allowance money
   - View spending reports
   - Change settings
   - Export financial reports

## 🎨 Design Philosophy

MoneyCoach Jr. is designed with children in mind:
- **Visual Learning**: Uses emojis, colors, and progress bars
- **Positive Reinforcement**: Celebrates achievements and milestones
- **Simple Navigation**: Easy-to-understand interface
- **Safe Environment**: No internet required, data stays local

## 📊 Data Storage

All data is stored locally in the browser using localStorage:
- User profile and balance
- Expense history
- Savings goals (active and completed)
- Parent settings

## 🔒 Security & Privacy

- **Local Storage Only**: No data is sent to external servers
- **PIN Protection**: Parent features are secured with a 4-digit PIN
- **No Registration**: No personal information required
- **Offline Capable**: Works without internet connection
